# Experiment Overview

## synthetic_validation_paper

This experiment is the scaled reproduction counterpart of the paper's aggregate synthetic fixed-time validation. It asks whether fixed-time renderings are closer to a known static target than a comparable dynamic reconstruction baseline while preserving inference-time state size.

The scored result averages every generated validation scene available in the standard output layout. The diagnostics file keeps the canonical scene and extra-scene summaries separate so regressions on individual scenes remain visible.
